# 循环 ONNX 策略

运行时接受前馈策略，以及 mjlab/rsl_rl 生成的显式状态 LSTM 导出。两者都以 50 Hz 消费现有的 61 维观测，并产生同样的 14 个原始关节动作。观测归一化必须烘焙进导出的模型。训练用的 critic 不会被部署。这不会增加任何传感器或动作过滤。

## 模型契约

所有张量都是 float32。输入和输出按名字匹配，与顺序无关。

| 模型 | 输入 | 输出 |
| --- | --- | --- |
| 前馈 | `obs [1, 61]` | 一个输出 `[1, 14]`（仍接受已有的输出名字） |
| LSTM | `obs [1, 61]`、`h_in [layers, 1, hidden]`、`c_in [layers, 1, hidden]` | `actions [1, 14]`、`h_out [layers, 1, hidden]`、`c_out [layers, 1, hidden]` |

批量维可以是符号化的；推理始终只针对一个机器人。层数与隐层宽度必须是正的静态维，且在这四个状态张量之间完全一致。每个状态最多 1,048,576 个元素。不支持的名字、秩、类型、宽度以及多余张量都会在加载时失败。预热同样会拒绝无效或非有限的输出。GRU 及其他循环导出签名尚未实现。

发布循环策略时使用 **`model_api: 2`**，这样较旧的守护进程会在安装之前就拒绝它们。这个守护进程也接受现有的 API 1 前馈模型。manifest schema、观测宽度与动作宽度保持不变。

## 记忆生命周期

每个已加载的策略都拥有预先分配的隐状态与细胞状态张量。每次成功推理都会把两个新状态拷贝进这些缓冲区。失败的推理会清空记忆；非有限输出会在任一状态提交之前被拒绝。预热产生的状态会被丢弃。

记忆在以下情形从零开始：初次激活、切换网络（包括切换回来）、显式禁用、暂停或跌倒恢复后的控制器重置，以及一个链式技能的重新启动。短暂传感器掉线遵循现有的恢复宽限期。在某个仍活跃的网络内改变命令会保留记忆。

替换一个非活跃槽位时，只有当它的 ONNX 文件具有相同的 SHA-256 摘要，才会保留活跃网络的记忆。一个被改变过的活跃模型即使在同一文件路径，也会从头开始。要获得这一保证，请使用自包含的 ONNX 导出：外部引用的权重文件不属于 ONNX 文件摘要的一部分。显式的控制器重置总是清空所有槽位。

现有的动作缩放与可选运行时过滤器保持各自的配置。对于没有使用动作过滤训练的某个策略，请在其部署调参中禁用这些过滤器；加入循环性不会让一个不匹配的过滤器配置变得合法。

## 离线预演与板上计时

这个示例使用生产级的 Rust 推理路径，并且从不打开电机总线：

```sh
export ORT_DYLIB_PATH=/path/to/libonnxruntime.so
cargo run --release -p duck-control --example policy-rehearsal -- policy.onnx > rehearsal.json
```

它会预热 actor、清空状态，然后在标称重力、零命令与前次动作反馈的条件下测量 1,000 次推理。JSON 中包含 p50/p95/p99/max 延迟、超过 20 ms 的次数，以及动作。请**在 Radxa 上**运行构建出来的示例来确立板上计时；开发机上的计时无法确立机器人的计时预算。这些计时不包括传感器读取、电机写入与调度延迟。

要与 PyTorch 或 Python ONNX Runtime 做确定性的多步对比，把记录的 JSON 数组作为第二个参数传入：

```json
[{"obs": ["replace with exactly 61 numbers"], "reset": true}]
```

每条记录提供完整的观测，包括前次动作。在回合边界处设置 `reset`。把返回的动作序列与使用相同观测和重置的参考实现做对比。这检查的是推理与记忆处理，而不是物理上的 sim2real 迁移。请通过训练仓库的归一化导出器导出训练好的检查点。

## 测试

```sh
cargo test -p duck-control
# 需要 ONNX Runtime >= 1.23：
cargo test -p duck-control --test recurrent_policy -- --ignored
cargo test -p robotd recurrent_memory_resets_with_controller_feedback -- --ignored
```

检入的迷你夹具使用了真正的 ONNX LSTM 算子。它们覆盖记忆连续性、重置、策略切换、回退选择、预热、热替换、动态批量维、非法契约与非有限状态。在有 `onnx` 和 `numpy` 的环境里用 `python duck-control/tests/fixtures/generate.py` 重新生成。
